# GitHub profile guidance

This public repository renders `README.md` on the GitHub profile. Application source belongs in the separate portfolio repository.

- Keep career and project claims supported by public evidence. Preserve working links and distinguish personal work from employer work.
- Do not copy private project plans, family details, the personal voice profile, credentials, or employer/client material into this repository.
- For writing as Jon, use the approved private `write-as-me` skill through the personal connection; keep its source private.
- This repository has no application build or test suite. Check Markdown rendering, destinations of changed links, and `git diff --check` before a PR. Do not invent install or test commands.
- Keep these standing rules here; the profile itself belongs in `README.md`.
